# PHD Stefan Paving

A CUDA solver for a three-dimensional Stefan problem involving multiple briquettes. It
models heat transfer and phase change across the briquettes and surrounding material on a
regular 3D grid.

CUDA-решатель трёхмерной задачи Стефана для системы из нескольких брикетов. Моделирует
перенос тепла и фазовые переходы в брикетах и окружающем материале на регулярной трёхмерной
сетке.

## Описание

Начальные температуры брикетов и окружающей среды различаются. В области фазового
перехода учитываются зависящие от температуры свойства материала.

Программа является исследовательским кодом с параметрами эксперимента, заданными непосредственно в исходниках. Она записывает текстовую сводку и снимки VTK, которые затем можно просматривать средствами научной визуализации.

## Разработка и проверка изменений

**Основные точки изменения:**

- `src/paving.cu` - численная модель нескольких брикетов, CUDA-ядра и вывод данных;
- `CMakeLists.txt` - сборка CUDA-программы.

**Температурные свойства:** в `src/paving.cu` CUDA-функция `c_ro(t)`
рассчитывает объёмную теплоёмкость с учётом интервала фазового перехода
и скрытой теплоты; `k(t)` задаёт температурно-зависимую теплопроводность.
Обе вызываются ядром `solve`, а границы перехода определяются
`freeze_temp_d` и `delt_d`. Изменяя модель материала, проверяйте
согласованность этих функций с формулой обновления температуры в `solve`.

**Проверка изменений:** При изменении геометрии или теплообмена проверяйте согласованность индексов трёхмерной сетки, граничных условий и параметров шага. Выполните сборку и контрольный запуск по инструкциям выше.

## Сборка

Нужны CMake, CUDA Toolkit и совместимый NVIDIA GPU.

```sh
cmake --preset release
cmake --build --preset release
```

Исполняемый файл:

```text
build/release/paving
```

## Запуск

```sh
mkdir -p plot
./build/release/paving
```

Параметров командной строки нет. Температуры, размер брикетов, количество элементов, шаг сетки и шаг времени задаются непосредственно в `src/paving.cu`.

## Результат

Основные численные результаты записываются в `out.txt`. Поля температуры периодически сохраняются в бинарных VTK-файлах:

```text
plot/result_<time>.vtk
```

## Модель

Расчет использует трехмерную явную конечно-разностную схему. В начальном условии внутри объема размещается набор брикетов, окруженных другой средой; теплообмен и фазовый переход рассчитываются во времени на GPU.
